The segmental reconciliation problem can be seen as a combination of two independent problems: on the one hand, that of the bilateral reconciliation of the synteny tree with the host tree, and on the other hand, that of inferring the ancestral content groups of the syntenies.
In this chapter, we show that the algebraic approach presented in \cref{chap:adp} makes it possible to render this intuition precise and concrete.
We independently give an algebraic treatment of each of the two problems in \cref{sec:adp-rec:bilateral,sec:adp-rec:set} and then show how to combine their solutions to solve segmental reconciliation in \cref{sec:adp-rec:both}.

\section{Bilateral reconciliation}\label{sec:adp-rec:bilateral}

In order to solve \(\recmodelDTLx\)-parsimony \cref{prob:reconciliation:parsimony} for bilateral reconciliation through the algebraic approach, we develop in this section a grammar describing the solution space as well as a collection of algebras for evaluating these solutions.
As a reminder, the input of this problem consists of a tree of units \(T\), a host tree \(S\), as well as a map \(\llmap : \tleavs(T) \onto \tleavs(S)\) associating each extant unit of \(T\) with its host in \(S\).
The objective is to identify the reconciliations that have the most parsimonious interpretations, that is, the reconciled trees that explain the input using as few events as possible.

We set as the signature of the problem, in the sense of \cref{def:adp:alg}, the set of operators \(\algsignrec = \{\algnull, \algplus, \evLeaf, \evSkip, \evSpe, \evDup, \evTr\}\) defined as follows:
\begin{itemize}
    \item \(\evLeaf_{t,v}\) represents an extant unit \(t \in \tleavs(T)\) whose host is \(v \in \tleavs(S)\);
    \item \(\evSkip_n(h)\) represents a jump to a descendant at distance \(n\) from the current host, which can be interpreted as a succession of \(n\) \(\evtS\) and \(\evtL\) events, or as a single \(\evtTX\) event;
    \item \(\evSpe_{t,v}(h_L, h_R)\), \(\evDup_{t,v}(h_L, h_R)\) and \(\evTr_{t,v}(h_L, h_R)\) respectively represent events of type \(\evtS\), \(\evtD\) and \(\evtT\) concerning the unit \(t \in \tnodes(T)\) associated with the host \(v \in \tnodes(S)\).
\end{itemize}

This signature makes it possible to represent any set of parsimonious reconciled trees under the~\(\recmodelDTLx\) model and thus to represent the solution space of the problem under consideration.

\subsection{Evaluation algebras}

For any cost function \(\cost : \recmodelDTLx \onto \realpos \cup \{\infty\}\), we can define the following optimization algebra~\(\alminplus_\cost\) respecting the signature~\(\algsignrec\):\\
\sidecols{.5\textwidth}{.5\textwidth}{
\begin{align*}
    \algnull &= \infty \\
    \algplus &= \min \\
    \evLeaf_{t,v} &= 0 \\
    \evSpe_{t,v}(h_L, h_R) &= h_L + h_R
\end{align*}
}{
\begin{align*}
    \evDup_{t,v}(h_L, h_R) &= h_L + h_R + \cost(\evtD) \\
    \evTr_{t,v}(h_L, h_R) &= h_L + h_R + \cost(\evtT) \\
    \evSkip_{n}(h) &= h + \min\{n\cost(\evtL), \cost(\evtTX)\}. \\
\end{align*}
}

This algebra is additive and can therefore be converted into a Boltzmann algebra (see \cref{sec:adp:space-enum-sample}) in order to sample optimal and near-optimal solutions.

As with any signature, a trace algebra \(\altrace(\algsignrec)\) can be built in order to construct the algebraic circuits representing the solution space associated with a given input (see \cref{sec:adp:solution-spaces:trace}).
This makes it possible, for example, to automatically construct the set of minimum-cost solutions, using the combined algebra \(\alminplus_\cost \times \altrace(\algsignrec) \mid \allex{1}\).

In the absence of a fixed cost function, it may be desirable to perform multiobjective optimization, by building sets of Pareto-optimal vectors of the form \(\tup{n_\evtD, n_\evtT, n_\evtL, n_\evtTX}\) counting the number of events of each type.
This task is complicated by the fact that the operator \(\evSkip_n(h)\) can be interpreted either as a series of~\(\evtL\) events, or as a single~\(\evtTX\) event, depending on the relative cost of these two events.
Each call to \(\evSkip_n(h)\) must therefore generate two vectors representing these two possible interpretations, which prevents us from using the generic construction of \cref{sec:adp:alg-combin:pareto}.
We therefore construct the algebra manually as follows: \\
\sidecols{.35\textwidth}{.65\textwidth}{
\begin{align*}
    \algnull &= \emptyset \\
    h \algplus h' &= \parfront(h \cup h') \\
    \evLeaf_{t,v} &= \{\tup{0, 0, 0, 0}\} \\
    \evSpe_{t,v}(h_L, h_R) &= \parfront(h_L + h_R) \\[-3.2ex]
\end{align*}
}{
\begin{align*}
    \evDup_{t,v}(h_L, h_R) &= \parfront(h_L + h_R + \{\tup{1, 0, 0, 0}\}) \\
    \evTr_{t,v}(h_L, h_R) &= \parfront(h_L + h_R + \{\tup{0, 1, 0, 0}\}) \\
    \evSkip_n(h) &= \begin{cases}
        h & \text{if } n = 0 \\
        \parfront(h + \{\tup{0, 0, n, 0}, \tup{0, 0, 0, 1}\}) & \text{otherwise,}
    \end{cases}
\end{align*}
}\\
where \enquote{\(+\)} corresponds to a Minkowski sum, which constructs the set of sums of the pairs of vectors obtained by taking the Cartesian product of the two operands.

\subsection{Yield grammar}

The space of reconciliations has been formally studied by several authors, notably \textcite{Doyon2009SpaceGeneSpeciesTrees} for the \(\recmodelDL\) model.
More recently, \textcite{Chauve2020CountingSamplingGene} proposed a grammar describing the space of reconciled trees under the \(\recmodelDTL\) model, without constraints on the tree of units.
In this section, we propose a canonical grammar for the space of reconciliations under the \(\recmodelDTLx\) model.

The grammar \(\gramrec\), presented following the conventions of \cref{sec:adp:yield-gram}, uses four predicates, each representing a set of possible reconciliations of the subtree \(T\) given in their first dimension.
These predicates are defined as follows:
\begin{compactitemize}
    \item \(\gRec[T, S]\): reconciliations such that \(\troot(T)\) is matched with \(\troot(S)\);
    \item \(\gRecOut[T, S]\): such that \(\troot(T)\) is matched with any host \(s \nottcomp \troot(S)\);
    \item \(\gRecIn[T, S]\): such that \(\troot(T)\) is matched with any host \(s \tdesc \troot(S)\);
    \item \(\gRecPath[T, S, 0]\): such that \(\troot(T)\) is matched with any host \(s \tdesc \troot(S)\) and preceded by a \(\evSkip_N\) event with \(N = \tdist(s, \troot(S))\).
\end{compactitemize}
The solution space for two phylogenies \(T\) and \(S\) is generated by \(\gRecIn[T, S]\).\\
The clauses of the grammar are:
{\allowdisplaybreaks
\begin{subequations}
\begin{align}
    \gRec[t(), v()] &\rightarrow \evLeaf_{t,v}
    \qquad\text{\itshape\small (only when \(\llmap(t) = v\))} \label{eq:adp-rec:bilateral-grammar-leaf}\\[2ex]
    \gRec[t((T') \mid (T'')), v((S_L)(S_R))] &\rightarrow
        \evSpe_{t,v}(\gRecPath[(T'), (S_L), 0], \gRecPath[(T''), (S_R), 0]) \label{eq:adp-rec:bilateral-grammar-spe} \\
    \gRec[t((T_L)(T_R)), v(S)] &\rightarrow
        \evDup_{t,v}(\gRecPath[(T_L), v(S), 0], \gRecPath[(T_R), v(S), 0]) \label{eq:adp-rec:bilateral-grammar-dup} \\
    \gRec[t((T') \mid (T'')), v(S)] &\rightarrow
        \evTr_{t,v}(\gRecOut[(T'), v(S)], \gRecPath[(T''), v(S), 0]) \label{eq:adp-rec:bilateral-grammar-tr} \\[2ex]
    \gRecPath[T, v((S') \mid S''), N] &\rightarrow \gRecPath[T, S', N+1] \label{eq:adp-rec:bilateral-grammar-path-down}\\
    \gRecPath[T, S, N] &\rightarrow \evSkip_N(\gRec[T, S]) \label{eq:adp-rec:bilateral-grammar-path-end}\\
    \gRecIn[T, v((S') \mid S'')] &\rightarrow \gRecIn[T, S'] \label{eq:adp-rec:bilateral-grammar-in-down}\\
    \gRecIn[T, S] &\rightarrow \gRec[T, S] \label{eq:adp-rec:bilateral-grammar-in-end}\\[2ex]
    \gRecOut[T, S \text{ sibling of } S'] &\rightarrow
        \gRecIn[T, S'] \label{eq:adp-rec:bilateral-grammar-out-side}\\
    \gRecOut[T, P \text{ parent of } S] &\rightarrow
        \gRecOut[T, P] \label{eq:adp-rec:bilateral-grammar-out-up}
\end{align}
\end{subequations}}%
Following the conventions of \cref{sec:adp:yield-gram}, the notation \((T')\mid(T'')\) indicates that \(T'\) and \(T''\) are the two child subtrees of the root, taken in any order, whereas the notation \((T_L)(T_R)\) indicates that the order of the input is preserved.

Clauses \labelcref{eq:adp-rec:bilateral-grammar-spe,eq:adp-rec:bilateral-grammar-dup,eq:adp-rec:bilateral-grammar-tr} act at the level of the internal nodes of the tree \(T\) to insert cospeciation, duplication or transfer events there.

Clauses \labelcref{eq:adp-rec:bilateral-grammar-path-down,eq:adp-rec:bilateral-grammar-path-end,eq:adp-rec:bilateral-grammar-in-down,eq:adp-rec:bilateral-grammar-in-end} traverse the hosts descending from a given node,
either by keeping track of the number of nodes traversed in order to insert a call to \(\evSkip_N\)~(\(\gRecPath\)),
or by continuing directly with a reconciliation at the level of the descendant, as at the beginning of a reconciliation or following a transfer event~(\(\gRecIn\)).

Finally, clauses \labelcref{eq:adp-rec:bilateral-grammar-out-side,eq:adp-rec:bilateral-grammar-out-up} make it possible to traverse the hosts separated from a given node.
They rely on the recursive principle according to which a node separated from \(v\) is either a descendant of a sibling of~\(v\), or a node separated from the parent of \(v\).
This principle was used by \textcite{Bansal2012EfficientAlgorithmsReconciliation} to reduce the complexity of the \(\recmodelDTL\)-parsimony algorithm by a factor of \(|\tnodes(S)|\).

We conjecture that this grammar is unambiguous and that it is canonical for the \(\recmodelDTLx\)-parsimony problem in the sense that each possible parsimonious reconciliation for a given input is enumerated exactly once.

Thanks to \cref{alg:seq-yield-parser}, this grammar automatically corresponds to a dynamic programming algorithm.
Its time complexity is \(\bigo(nmd)\)\footnote{This complexity only takes into account the time needed to construct the algebraic circuit associated with a given input. Depending on the algebra used to evaluate this circuit, the total complexity could be higher. In the case where only the minimum cost of a solution, or only the construction of an arbitrary solution achieving this cost, is sought, the complexity is exactly as stated.}, where \(n\) and \(m\) are the sizes of \(T\) and \(S\) and \(d\) is the depth of \(S\), by virtue of \cref{thm:adp:gram-hedge-complex}.
This complexity is close to the best known complexity for the bilateral reconciliation problem \parencite{Weiner2021ImprovedDuplicationTransfer}, up to a factor of \(d\).
This factor can, however, be eliminated by removing the parameter \(N\) from the predicate \(\gRecPath\), by inserting instead a call to \(\evSkip_1\) at each application of clause \labelcref{eq:adp-rec:bilateral-grammar-path-down}, and by adding a separate clause to infer \(\evtTX\) events.
However, this transformation makes the grammar non-canonical, since there then always exist two partial solutions connecting two nodes of~\(T\), one taking a series of calls to \(\evSkip\), the other taking the new clause for \(\evtTX\) events.

It is possible to extend this grammar to solve the problem of binarizing a tree \(T\) containing polytomies so as to minimize the associated \(\recmodelDTLx\) reconciliation cost.
The complexity of the resulting algorithm, by virtue of \cref{thm:adp:gram-forest-complex}, is \(\bigo(n^22^{\deg I})\), that is, it is a \emph{fixed parameter tractable} (FPT) algorithm in the maximum degree of the tree of units.
This complexity is comparable to that of the algorithm developed by \textcite{Kordi2016ExactAlgorithmsDuplicationTransferLoss}.

\section{Group parsimony}\label{sec:adp-rec:set}

The group parsimony problem, which underlies segmental reconciliation, concerns the inference of the ancestral content of syntenies in a tree whose content at the leaves is known.
This inference relies on a model of grouped gains and losses, such that each edge of the tree can be labelled with a gain event that simultaneously makes one or more new units appear, or with a loss that makes some of them disappear.
We will make Dollo's hypothesis, according to which each unit is gained exactly once.

The objective of the problem is to find a most parsimonious labelling of ancestral contents in terms of gains and losses, depending on the number of events and on their respective sizes.
More precisely, each internal node must be labelled with a group so as to minimize the cost formed by the sum, over each branch \((v, v\child)\), of \(\cost_\evtG(|\syntenyOfExt(v\child) - \syntenyOfExt(v)|)\) and \(\cost_\evtL(|\syntenyOfExt(v) - \syntenyOfExt(v\child)|)\).
An example of an instance of the problem is presented in \cref{fig:adp-rec:set-example}.

\begin{problem}{Group parsimony}
    \probinput{Phylogeny \(T\);
               set of units \(\geneFamilySet\);
               labelling \(\syntenyOf : \tleavs(T) \onto 2^{\geneFamilySet}\);\newline
               costs \(\cost_\evtG, \cost_\evtL : \nat \onto \realpos\).}
    \proboutput{Minimum-cost assignment \(\syntenyOfExt : \tnodes(T) \onto 2^{\geneFamilySet}\) extending \(\syntenyOf\).}
\end{problem}

A first version of the problem was studied by \textcite{Delabre2020EvolutionSegmentalDuplications}, ignoring the size of losses and assuming that all units are gained at the root of the tree.
During the spring of~2025, Corélie~\textsc{Godefroid} studied the version of this problem extended to also place gain events optimally.
These ideas were developed by Mathieu~\textsc{Gascon}, leading to an article presented at the RECOMB-CG~2026 conference \parencite{Gascon2026GeneRepertoireEvolution}.
The solution presented in the remainder of this section is based on this work.

\subsection{Reducing the problem}

Let us observe that this problem can be seen as pertaining to the size of the ancestral groups rather than to their content.
Indeed, since the cost functions under consideration depend only on the number of gain and loss events and on the number of units gained and lost, two solutions that infer the same ancestral group sizes are indistinguishable from the point of view of their cost and will be considered equivalent in what follows.
The problem is thus related to the one solved by the Count program of \textcite{Csuros2010CountEvolutionaryAnalysis}, which infers ancestral copy-number profiles of a gene family based on a probabilistic model.

Some constraints nevertheless exist on the sizes of the ancestral groups.
At each internal node \(v \in \tnodes(T)\), the set of units~\(\geneFamilySet\) can be partitioned into three subsets \(\geneFamilySet = \xmin(v) \cup \xin(v) \cup \xout(v)\), where:
\begin{compactitemize}
    \item \(\xmin(v)\) is the set of units whose \emph{lca} is an ancestor of \(v\) and that appear in at least one leaf of the subtree of \(v\);
    \item \(\xout(v)\) is the set of units that do not appear in any leaf of the subtree of \(v\);
    \item \(\xin(v)\) is the set of units whose \emph{lca} is a strict descendant of \(v\).
\end{compactitemize}
Because of Dollo's hypothesis, the units of \(\xmin(v)\) appear in the set \(\syntenyOfExt(v)\) in every solution.
Conversely, \(\xout(v)\) and \(\xin(v)\) contain units that may optionally appear in it: in the case of \(\xout(v)\), they can be freely lost in the branch leading to \(v\) and, in the case of \(\xin(v)\), they can be freely gained there.

To represent the solution space of the problem, we therefore set as signature the set of operators \(\algsignset = \{\algnull,\allowbreak \algplus,\allowbreak \evLeaf,\allowbreak \evGain,\allowbreak \evLoss,\allowbreak \evSplit\}\) defined as follows:
\begin{itemize}
    \item \(\evLeaf\) represents a leaf of the tree;
    \item \(\evGain_N(h)\) and \(\evLoss_N(h)\) respectively represent a gain or a loss of \(N\) units;
    \item \(\evSplit_{G_L,G_R,L}(h_L, h_R)\) represents an internal node of the tree at which \(G_L+G_R\) units remain to be gained, of which \(G_L\) in the left subtree and \(G_R\) in the right subtree, and \(L\) units remain to be lost.
\end{itemize}

\subsection{Evaluation algebras}

For two given cost functions \(\cost_\evtG\) and \(\cost_\evtL\), this signature makes it possible to define the following additive optimization algebra \(\alminplus_{\cost_\evtG,\cost_\evtL}\)\\
\threecols{.33\textwidth}{.33\textwidth}{.33\textwidth}{
\begin{align*}
    \algnull &= \infty \\
    \evGain_N(h) &= h + \cost_\evtG(N)
\end{align*}
}{
\begin{align*}
    \algplus &= \min \\
    \evLoss_N(h) &= h + \cost_\evtL(N)
\end{align*}
}
{
\begin{align*}
    \evLeaf &= 0 \\
    \evSplit_{G,G',L}(h_L, h_R) &= h_L + h_R.
\end{align*}
}

As before, this algebra can be adapted into a Boltzmann or a Pareto algebra.

Note that the functions \(\cost_\evtG\) and \(\cost_\evtL\) can be arbitrary.
A constant cost, that is, of the form \(\cost_e(n) = b_e\) if \(n \ge 1\) and \(0\) otherwise, for a constant \(b_e \in \realpos \cup \{\infty\}\), makes it possible to minimize the number of events without taking into account the size of gains and losses.
The problem then becomes equivalent to the problem underlying the segmental reconciliation of \textcite{Delabre2020EvolutionSegmentalDuplications} and of \cref{chap:superdtl,chap:synesth}.
The solutions obtained with these costs tend to group many events together and to generate an excessive number of losses.

A linear cost, that is, of the form \(\cost_e(n) = a_en\) for a constant \(a_e \in \realpos \cup \{\infty\}\), makes it possible to search for the solutions minimizing the total size of the events.
It makes the problem equivalent, however, to individual Dollo parsimony, since the units can then be considered as evolving independently.

More generally, an affine cost of the form \(\cost_e(n) = a_en + b_e\) if \(n \ge 1\) and \(0\) otherwise, for two constants \(a_e, b_e \in \realpos \cup \{\infty\}\), simultaneously takes into account the dependence between the studied units while giving preference to more parsimonious solutions that globally minimize the size of the events.
In what follows, the constants \(b_e\) are called the opening costs and the constants \(a_e\) the extension costs of gains or losses.

\subsection{Yield grammar}

The solution space can be described by a grammar \(\gramset\) of dimension three.
The first dimension \(T\) represents the subtree being processed.
The second dimension \(G\) represents the number of units remaining to be gained in the subtree being processed.
The third dimension \(L\) represents the number of units of the set \(\xout\) that are present, that is, that have already been gained but do not appear in any leaf of the subtree being processed.
The grammar uses three predicates defined as follows:
\begin{compactitemize}
    \item \(\gSplit[T, G, L]\) represents the solutions whose root is \(T\) and below which \(G\) units remain to be gained and \(L\) to be lost;
    \item \(\gBranch[T, G, L]\) and \(\gBranch'[T, G, L]\) represent the solutions that add unary loss and gain events above \(T\).
\end{compactitemize}
At each level of the solution, it must be ensured that \(G\) does not exceed the number of units that can potentially be gained in the subtree being processed.
More precisely, for each internal node \(v\), let \(\xlca(v)\) denote the set gathering all units whose \(\lca\) is a descendant of \(v\), that is, the units that can be gained at \(v\) or below.
Each call to one of the three predicates thus leads to a valid solution only if \(G \le |\xlca(v)|\).

The set of solutions consists of the terms derived from \(\gBranch[T, |\geneFamilySet|, 0]\), where \(T\) is the input tree and \(\geneFamilySet\) the set of all units.
The clauses of the grammar are:
{\allowdisplaybreaks
\begin{subequations}
\begin{align}
    \gSplit[(), 0, 0] &\rightarrow \evLeaf \label{eq:adp-rec:set-split-leaf} \\[2ex]
    \begin{aligned}
        &\gSplit[t(t\lchild(T_L)\,t\rchild(T_R)), G_L + G_R, L] \\
        \rightarrow\ & \evSplit_{G_L, G_R, L}(
            \begin{aligned}[t]
                &\gBranch[t\lchild(T_L), G_L, L + |\xlca(t\rchild)| - G_R + |\xmin(t) - \xmin(t\lchild)|], \\
                &\gBranch[t\rchild(T_R), G_R, L + |\xlca(t\lchild)| - G_L + |\xmin(t) - \xmin(t\rchild)|])
            \end{aligned} \\
        &\text{\itshape\small (only when \(|\xlca(t\lchild)| \ge G_L\) and \(|\xlca(t\rchild)| \ge G_R\))}
    \end{aligned} \span \label{eq:adp-rec:set-split-inner}\\[2ex]
    \gBranch[T, G, L_H + L_D] &\rightarrow \evLoss_{L_H}(\gBranch'[T, G, L_D]) \label{eq:adp-rec:set-split-loss}\\
    \gBranch'[T, G_H + G_D, L] &\rightarrow \evGain_{G_H}(\gSplit[T, G_D, L]). \label{eq:adp-rec:set-split-gain}
\end{align}
\end{subequations}}%
Clause \labelcref{eq:adp-rec:set-split-inner} applies to each internal node of \(T\).
Each of the \(G\) units that remain to be gained at a given internal node can be gained either in the left subtree or in the right subtree, hence the decomposition \(G = G_L + G_R\).
Each of the \(L\) units that come from the set \(\xout(t)\) are by definition elements of the sets \(\xout(t\lchild)\) and \(\xout(t\rchild)\), to which must be added the units that will be gained on the other side (resp. \(|\xmin(t) - \xmin(t\lchild)|\) and \(|\xmin(t) - \xmin(t\rchild)|\)) and those that have already been gained but are no longer needed in the current subtree (resp. \(|\xlca(t\rchild)| - G_R\) and \(|\xlca(t\lchild)| - G_L\)).

Clauses \labelcref{eq:adp-rec:set-split-loss,eq:adp-rec:set-split-gain} respectively introduce a loss and a gain of a number of units at most equal to the current value of \(L\) or of \(G\).

We conjecture that this grammar is unambiguous and that it is canonical for the group parsimony problem, that is, that each scenario is enumerated exactly once, considering only the size of the groups and not their exact content.

Thanks to \cref{alg:seq-yield-parser}, this grammar automatically corresponds to a dynamic programming algorithm.
By virtue of \cref{thm:adp:gram-hedge-complex}, its time complexity is \(\bigo(nf^3)\), where \(n\) is the size of \(T\) and \(f\) the number of units in \(\geneFamilySet\).
Separating the two clauses \labelcref{eq:adp-rec:set-split-loss,eq:adp-rec:set-split-gain} is necessary to keep a complexity in \(f^3\) instead of \(f^4\).

The solutions of the solution space thus generated do not directly describe the content of the ancestral groups, but only their respective sizes.
However, it is easy to determine an example of content for any solution using the sets \(\xmin(v)\), \(\xin(v)\) and \(\xout(v)\).

\section{Segmental reconciliation}\label{sec:adp-rec:both}

The segmental reconciliation problem, introduced in \cref{sec:reconciliation:multiple:segmental}, can be seen as requiring the simultaneous solution of a bilateral reconciliation problem and of a set parsimony problem, while respecting certain additional constraints.

To solve this problem, we propose combining the grammars \(\gramrec\) and \(\gramset\) into a grammar \(\gramseq\).
This approach offers a simplified route to recover the constructions of \cref{chap:superdtl,chap:synesth}.
To the best of our knowledge, no general method is currently known for combining such grammars.
In what follows, we therefore carry out an ad hoc construction from which more general principles may be drawn in future research.

Intuitively, this combination is achieved by taking the Cartesian product of the sets of predicates of the two grammars, and then of their sets of clauses.
Each pair of predicates thus obtained acts simultaneously on the dimensions \(T\), \(S\) and \(N\) of \(\gramrec\) and on the dimensions \(T\), \(G\) and \(L\) of \(\gramset\), the dimension \(T\) being shared between the two grammars.
Each pair of clauses is combined when the patterns of their heads are compatible on this shared dimension.
The bodies of the clauses are combined in an ad hoc manner.
The resulting clauses are presented below and in \cref{tab:adp-rec:product}.
{\allowdisplaybreaks
\begin{subequations}
\begin{align}
    \gRecSplit[t(), v(), 0, 0] &\rightarrow \evLeaf_{t,v}
    \qquad\text{\itshape\small (only when \(\llmap(t) = v\))} \label{eq:adp-rec:comb-grammar-leaf}\\[2ex]
    \begin{aligned}
        &\gRecSplit[t(t'(T') \mid t''(T'')), v((S_L)(S_R)), G_L + G_R, L] \\
        \rightarrow\ & \evSpe_{t,v,G_L,G_R,L}(
            \begin{aligned}[t]

    \end{aligned} \span \label{eq:adp-rec:comb-grammar-spe} \\[1ex]
    \begin{aligned}
        &\gRecSplit[t(t'(T') \mid t''(T'')), v(S), G_L + G_R, L] \\
        \rightarrow\ & \evDup_{t,v,G_L,G_R,L}(
            \begin{aligned}[t]

            \end{aligned} \\[-2ex]
        \intertext{\hspace*{3em}\itshape\small (only when \(|\xlca(t')| \ge G_L\) and \(|\xlca(t'')| \ge G_R\))}
    \end{aligned} \span \label{eq:adp-rec:comb-grammar-dup} \\[1ex]

        &\gRecSplit[t(t'(T') \mid t''(T'')), v(S), G_L + G_R, L] \\
        \rightarrow\ & \evTr_{t,v,G_L,G_R,L}(
            \begin{aligned}[t]
                &\gRecOutBranch[t'(T'), v(S), G_L, 0], \\

        &\rightarrow \gRecPathBranch[T, S', N+1, G, L] \label{eq:adp-rec:comb-grammar-path-down} \\
    \gRecPathBranch[T, S, N, G, L_H + L_D]
        &\rightarrow \evSkip_N(\evLoss_{L_H}(\gRecBranchEnd[T, S, G, L_D])) \label{eq:adp-rec:comb-grammar-path-end} \\[2ex]
    \gRecInBranch[T, s((S') \mid S''), G, L] &\rightarrow \gRecInBranch[T, S', G, L] \label{eq:adp-rec:comb-grammar-in-down} \\
    \gRecInBranch[T, S, G, L_H + L_D] &\rightarrow \evLoss_{L_H}(\gRecBranchEnd[T, S, G, L_D]) \label{eq:adp-rec:comb-grammar-in-end} \\[2ex]
    \gRecOutBranch[T, S \text{ sibling of } S', G, L] &\rightarrow \gRecInBranch[T, S', G, L] \label{eq:adp-rec:comb-grammar-out-side} \\
    \gRecOutBranch[T, P \text{ parent of } S, G, L] &\rightarrow \gRecOutBranch[T, P, G, L] \label{eq:adp-rec:comb-grammar-out-up} \\

\end{align}
\end{subequations}}

In the segmental reconciliation model, duplication and transfer events affect a subset of the original group.
This means that an arbitrary number of units may disappear on one of the two outgoing branches (in the case of a transfer, on the branch leading to the separated host), and this without requiring a loss event.
In order to encode this rule in the grammar \(\gramseq\), the dimension \(L\) has been set to 0 in the body of clauses \labelcref{eq:adp-rec:comb-grammar-dup,eq:adp-rec:comb-grammar-tr}, unlike clause \labelcref{eq:adp-rec:set-split-inner} from which they originate.
This implies that all units belonging to the set \(\xout(v)\) are lost without triggering a loss event.
Note that without this modification of the two clauses, the grammar \(\gramseq\) would be of little interest, since it would be equivalent to solving the two problems independently.

The grammar \(\gramseq\) thus constructed, combined with evaluation algebras built similarly to those of the previous sections, makes it possible to solve the segmental reconciliation problem.
For example, one of the solutions to the instance obtained by combining the examples of the two previous sections is presented in \cref{fig:adp-rec:syn-solution-best}.
Despite a similar cost function, compared to the solution of \cref{fig:adp-rec:rec-input}, this solution uses four transfer events and one duplication, instead of a single transfer and two duplications.
In return, these events make it possible to save some gain and loss events compared to the solution of \cref{fig:adp-rec:set-solutions}.

\section{Discussion}

The first dynamic programming algorithm for phylogenetic reconciliation with horizontal transfers, developed by \textcite{Hallett2004SimultaneousIdentificationDuplications}, was limited to producing an arbitrary optimal solution for a fixed cost.
Several years of research were necessary to obtain algorithms capable
of analysing the set of optimal solutions \parencite{Scornavacca2013RepresentingSetReconciliations},
of uniformly sampling optimal solutions \parencite{Bansal2013ReconciliationRevisitedHandling}
or of efficiently enumerating them \parencite{Donati2015EfficientTreeReconciliation},
of obtaining Pareto-optimal solutions independently of the costs \parencite{LibeskindHadas2014ParetoOptimalPhylogenetic},
or of efficiently enumerating equivalence classes of optimal solutions \parencite{Wang2022EfficientlySparseListing}.

In this chapter, we have shown that the algebraic dynamic programming methods introduced in the previous chapter make it possible to directly carry out this type of advanced analysis on the space of reconciliations.
This application illustrates the potential of the algebraic approach to accelerate research on combinatorial optimization algorithms.
It indeed enables cross-cutting advances by generalizing techniques developed for specialized problems and by applying them to a variety of problems.

Finally, we have also shown how an algorithm for the segmental reconciliation problem can be obtained by composing two algorithms that independently solve two aspects of the problem.
Further work remains to be done in this direction in order to obtain a formal construction of this composition.
