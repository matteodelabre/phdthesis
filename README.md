# Reconstructing the Evolutionary History of Genes in Synteny

This repo contains the source files for my Ph.D. thesis, [defended on July 30, 2026](https://www.youtube.com/watch?v=GKG8NLJtZh8).
This branch is an **unofficial translation to English** of the chapters originally in French.
The files were machine-translated and carefully checked for accuracy by the author.
Compile using the LuaLaTeX engine:

```shell
latexmk -lualatex -output-directory=build main.tex
```

The official version (in French) can be downloaded directly from the [University of Montréal website](https://doi.org/10.71781/36049).
The translated (unofficial) version can be downloaded from [the releases page](https://github.com/matteodelabre/thesis/releases).
Using BibLaTeX, this thesis should be cited as follows:

```bib
@thesis{Delabre2026ReconstructionLhistoireEvolutive,
  type = {phdthesis},
  title = {Reconstruction de l’histoire évolutive de gènes en synténie : approche algébrique pour le problème de la réconciliation segmentale},
  shorttitle = {Reconstruction de l’histoire évolutive de gènes en synténie},
  author = {Delabre, Mattéo},
  date = {2026-08},
  institution = {Université de Montréal},

  langid = {french},
}
```
