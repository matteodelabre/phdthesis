\section{mosaic --- Visualizing Pareto vectors}
\programdetails{https://github.com/matteodelabre/mosaic}{GPL v3.0}{Between December~2023 and April~2026, 200 lines of code}

In some combinatorial optimization problems, including reconciliation problems, the objective function may combine several independent quantities, such as the number of duplication, transfer and loss events.
One way to define this type of objective is to set a relative cost for each of the quantities to be minimized and to optimize the linear combination thus obtained.
The costs thus defined then become hyperparameters of the method.
Sometimes difficult to estimate, they have a considerable impact on the content of the solutions obtained.

To avoid setting explicit costs, an alternative solution consists in searching for the vectors whose dimensions are the different quantities under study and that are Pareto-optimal, that is, for which there exists at least one cost parameterization that makes them optimal.
This alternative was notably explored in \cref{chap:synesth}.

The \emph{mosaic} program makes it possible to visualize the cost regions associated with these Pareto vectors.
The cost region associated with a vector is defined as the set of points in the cost space that make this vector optimal with respect to all other vectors.
Since there is a finite number of such vectors, there is also a finite number of such regions.
As shown by \textcite{LibeskindHadas2014ParetoOptimalPhylogenetic}, these regions are intersections of half-spaces and are therefore convex polytopes that cover the entirety of the cost space.
Each region and its vector coincide with a set of solutions that correspond to the values of the different dimensions of the vector.
Each point of the cost space, and therefore each cost parameterization, corresponds to a set of solutions that is the union of those of the regions to which this point belongs.

To generate a representation of the cost regions, one must therefore solve the problem of enumerating the vertices of a convex polytope.
To do so, we use the \emph{\href{https://github.com/cddlib/cddlib}{cddlib}} library through the Python module \emph{\href{https://github.com/stephane-caron/pypoman}{pypoman}}.
Examples of diagrams produced by this tool are presented in \cref{fig:synesth:crispr-pareto,fig:adp-rec:rec-pareto,fig:adp-rec:set-pareto}.
